## Latest release: **Assets**

<https://github.com/blueish0930/Assets/releases/tag/26/07/19>

The release is titled **Assets**; `26/07/19` is its tag, which is what the URL still shows.

| Archive | Size | Contents |
| --- | --- | --- |
| `blueish.rar` | 211 MB | The node group assets — this is the package to download. It holds the Blender node group libraries and their generated thumbnails. |
| `file_part1.rar` | 883 MB | Older files from previous uploads, kept for reference. |
| `file_part2.rar` | 448 MB | Older files from previous uploads, kept for reference. |
| `file_part3.rar` | 2.0 GB | Older files from previous uploads, kept for reference. |

`file_part1` to `file_part3` are the legacy set: a single release asset is limited to 2 GB, so that
older collection was split into three volumes. You only need them if you are after the previous
files; for the node groups, `blueish.rar` is enough.

## Using the Blender assets

1. Download `blueish.rar` — the node group assets — and extract it.
2. In Blender open **Edit → Preferences → File Paths → Asset Libraries** and press `+`.
3. Point the new library at the extracted folder.
4. Open the Asset Browser and browse or append from there.

## 在 Blender 里使用

1. 从 Releases 下载 `blueish.rar`（节点组资产）并解压。
2. 在 Blender 里打开 **编辑 → 偏好设置 → 文件路径 → 资产库**，点 `+`。
3. 把这个资产库指向解压出来的文件夹。
4. 打开资产浏览器，即可浏览或追加资产。
